صدى العراق — الإصدار 4.0
معرّف البناء: SADA-4.0-R21.13-SECTION-SERVICE-VISIBILITY-20261121

مشروع Node.js للنشر على Railway.

أوامر التشغيل:
- البناء والفحص: npm run build
- الاختبارات: npm test
- التشغيل: npm start

إعدادات Railway:
- Builder: RAILPACK
- Build: npm run build
- Start: npm start
- Health check: /healthz
- Node: >=22.23.5 <23

راجع RELEASE_REPORT_AR.md للتفاصيل وDEPLOY_R40_AR.md للنشر والتحقق.

تنبيه: لا تتضمن الحزمة بيانات المستخدمين أو الطلبات أو الأرصدة المحلية داخل data/؛ لا تستبدل مجلد Railway Volume ولا تغيّر إعدادات Firebase عند النشر. خذ نسخة احتياطية أولاً.


التحديث R21.11: حد موحد للخدمات المجانية (استخدامان إجمالاً لكل حساب خلال 24 ساعة متحركة)، عدّ تنازلي وفتح تلقائي عند تحرير أول استخدام، وصف خدمة اختياري مع سياسة مشتركة، ونقل الخدمة من منصة إلى أخرى مع اختيار عدة أقسام. يتضمن أيضاً إصلاحات التفاصيل والحذف والشعار المحلي من الإصدارات السابقة. راجع RELEASE_REPORT_AR.md وDEPLOY_R40_AR.md.

التحديث الحالي R21.12: إصلاح زر حذف الأقسام الفارغة في شاشتي الإدارة القديمة؛ لم يعد حذف قائمة خدمات فارغة يعرض نجاحاً وهمياً، بل يحذف سجل القسم وترتيبه من Firebase ويتحقق من مخازن الخدمات. كما تم إصلاح قص أزرار تعديل/حذف الأقسام على الهاتف. الأقسام الفارغة لا تُحذف تلقائياً كي لا تختفي الأقسام التي أنشأها المدير استعداداً لإضافة خدمات؛ احذف القسم صراحةً من زر «حذف القسم».


التحديث الحالي R21.13: إصلاح ظهور الأقسام والخدمات الموجودة في لوحة الإدارة وعدم ظهورها في صفحة «طلب خدمة». يضيف الخادم روابط categoryMeta.serviceKeys إلى لقطة الكتالوج التي تستخدمها واجهة العميل، ويحوّل نطاقات المنصات إلى معرّفات الواجهة. كما يتحقق من روابط الأقسام باستخدام الكتالوج الكامل (الخدمات العادية والمجانية واليدوية) ومعرّفات الخدمة البديلة. هذا تعديل لبيانات العرض فقط ولا يحذف أو يعيد كتابة بيانات Firebase ولا يفعّل الخدمات المعطلة عمدًا. راجع تقرير الإصدار وتعليمات النشر.
