صدى العراق 4.0 — الإصدار R21.53
معرّف البناء: SADA-4.0-R21.48-PUBLIC-CAPTCHA-SESSION-RESTORE-FIX-AR-20261128-R21.53-ADMIN-INTERACTION-RESET-DEDUPED-LOADS-MOBILE-PERFORMANCE

هذه الحزمة مبنية على مسار الاستعادة R21.48 وتحتفظ بإصلاحات الإصدارات السابقة حتى R21.52. أعيد تنظيم طبقة التنقل الأساسية في لوحة الإدارة لتقليل تكرار التهيئة والتحميل، دون تغيير مخطط قاعدة البيانات أو حذف بيانات المشروع.

أبرز تغييرات R21.53:
- تجاوز سلسلة مغلفات التنقل القديمة للأقسام الأساسية: نظرة عامة، المدفوعات، الطلبات، المستخدمون، الخدمات، الإعدادات والرسائل، عبر موجّه مباشر يحدّث الصفحة فوراً.
- إبقاء مسار توافق للصفحات الإدارية المتخصصة التي لم تدخل ضمن الأقسام الأساسية.
- منع تكرار طلبات التحميل المتزامنة عند الضغط المتكرر على القسم نفسه.
- جعل تبديل تبويبات الخدمات والمستخدمين مباشراً مع الاحتفاظ بوظائف التبويبات الموجودة.
- إزالة معالج النقر العام لزر استرداد الخدمات، وربط الزر نفسه بمشغّل الاسترداد المحدد.
- إزالة تحميل الخدمات المكرر عند تهيئة قسم الخدمات أول مرة، ومنع تحميل بيانات التبويب نفسه مرتين أثناء الطلب.
- إيقاف إعادة تركيب واجهة الإدارة بعد كل ضغطة في الأقسام الأساسية؛ الإبقاء عليها للصفحات الإضافية فقط.
- تقليل أعمال الرسم والمؤثرات الثقيلة على شاشات الهاتف وتحسين استجابة اللمس.
- الاحتفاظ بإصلاحات الإحصائيات عبر مسار الخادم الإداري، وإصلاحات الكتالوج والفئات، وخط Tajawal، وتصميم الرصيد، واسترداد الخدمات وإعدادات الخدمات من الإصدارات السابقة.

الاختبارات المحلية المنفذة:
- npm test (مع تجاوز إصدار Node محلياً فقط؛ بيئة الاختبار 22.16.0 بينما النشر يتطلب 22.23.0 أو أحدث ضمن الإصدار 22).
- npm run test:load على خادم محلي وبيانات اصطناعية: 4,000 طلب API ناجح من 4,000 مع 100 اتصال متزامن، و1,000 استجابة HTML من نوع 304 ناجحة من 1,000.
- محاكاة نقرات للموجّه الجديد: فتح الأقسام، الخدمات والمستخدمين، التبويبات، صفحة الإعدادات والمدفوعات، زر الاسترداد، منع التحميل المكرر والرجوع للصفحات المتخصصة.
- اختبار HTTP محلي لمسار لوحة الإحصائيات على Firebase REST تجريبي، بما يشمل نجاح القراءة ورفض صلاحيات Firebase ورفض الجلسة غير الإدارية.
- تحليل كتل JavaScript المضمنة وفحص تطابق معرّفات الإصدار وملفات النشر.

حدود يجب معرفتها:
- الاختبارات الاصطناعية والمحاكاة لا تعادل النقر داخل Safari على جهاز المستخدم ولا تثبت اتصال Railway أو Firebase الإنتاجيين. لم يتم النشر إلى موقعك ولم يتم تشغيل عمليات استرداد أو طلبات مالية حقيقية.
- بيئة العمل Node.js 22.16.0 أقل من الحد المطلوب للنشر 22.23.0؛ استخدم تجاوز محلي للاختبار فقط.
- لا يوجد package-lock.json في المصدر، وتعذر الوصول إلى سجل npm من بيئة العمل لإنشائه؛ لذلك لم يتم التحقق بواسطة npm ci.
- يجب نشر النسخة على بيئة اختبار أو بعد نسخة احتياطية، ثم التحقق من معرّف البناء وتجربة الأزرار وسجلات Railway وFirebase ومزودي الخدمات الحقيقيين قبل اعتمادها نهائياً.
- لا يمكن ضمان خلو أي نظام متصل بخدمات خارجية من جميع الأعطال إلى الأبد.
