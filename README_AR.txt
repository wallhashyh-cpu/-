صدى العراق — الإصدار 3.2 / R20.18

هذا إصدار تصحيح توافق بناء Railway فوق وظائف R20.17.

الإصلاح:
- أعيد أمر Railway إلى npm run build مثل النسخة R20.15 السابقة.
- npm run build يفحص ملفات التشغيل المطلوبة وعلامات الإصدار دون الاعتماد على مجلد tests.
- npm test يبقى للتدقيق الكامل عند توفر مجلد tests.

الوظائف الموروثة من R20.17:
- Firebase هو المصدر الأساسي للخدمات والأقسام عند بدء التشغيل.
- استعادة الكتالوج تتم من لقطة النسخة الاحتياطية، مع حماية المستخدمين والأرصدة والطلبات الحالية.
- صفحة حسابي الجديدة ووظائفها محفوظة.

التشغيل:
- Node: >=22.23.5 <23 (نفس شرط المشروع السابق)
- التثبيت: npm install
- بناء Railway: npm run build
- تدقيق الاختبارات الكامل محلياً: npm test
- التشغيل: npm start

تنبيه:
- لا تحذف Railway Volume ولا تغيّر إعدادات Firebase.
- لا يحتوي ZIP على أسرار Firebase أو بيانات قاعدة الإنتاج.
