صدى العراق — الإصدار 3.2 / R20.19

هذا إصدار إصلاح استعادة كتالوج Firebase وحفظ الخدمات المختارة يدوياً، مع إزالة ملفات معاينة تصميم الحساب من حزمة التطبيق.

أهم ما تغير:
- عند فراغ services في Firebase مع وجود بيانات أقسام/ترتيب، يحاول الخادم أولاً استعادة كاش Railway فقط إذا تطابق عدد الخدمات وعدد الأقسام مع آخر سجل تحقق ناجح.
- إذا لم يوجد كاش موثّق، لا يرفع النظام كاشاً غير موثوق ولا يمسح بيانات Firebase. يسمح فقط بطلب الاستيراد اليدوي الذي وافق عليه المسؤول، مع الحفاظ على categoryMeta وproviderServices وcatalogOrder وإصدار الكتالوج، ثم يتحقق من الخدمات الجديدة بعد الحفظ.
- المستخدمون والأرصدة والطلبات لا تدخل ضمن عملية استعادة كتالوج الخدمات هذه.
- Railway يستخدم npm run build كما في الإصدار القديم الذي كان يعمل. الاختبارات الكاملة تبقى عبر npm test.
- أزيل account-preview.png وaccount-preview.html من مجلد وحزمة التشغيل؛ معاينة التصميم ليست ملفاً مطلوباً لتشغيل الموقع.
