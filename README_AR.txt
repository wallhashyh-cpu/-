صدى العراق — الإصدار 3.2 / R20.23

هذا الإصدار يجمع إصلاحات كتالوج Firebase وتسمية «عروض صدى العراق» وإضافة شعار التطبيق، مع إصلاح تصنيف الأقسام والأسماء العربية ومنع تكرار العرض دون حذف السجلات الأصلية.

أبرز ما يتضمنه R20.23:
- إضافة شعار صدى العراق الذي زوّدنا به المستخدم بصيغة WebP مضغوطة، إلى بطاقات المنصات ومكتبة صور الأقسام داخل لوحة الإدارة.
- استبدال التسمية الظاهرة لخيار استيراد جميع منصات المزود بـ «عروض صدى العراق»، مع الإبقاء على القيمة الداخلية all للتوافق مع البيانات القديمة.
- إضافة منصة «عروض صدى العراق» في صفحة إنشاء الطلب. تظهر خدمات العروض في صفحة «الكل» وفي منصة العروض، بينما تبقى خدمات Instagram وTikTok وغيرها ضمن منصاتها الأصلية.
- تثبيت القسم المستورد كعرض في أول قائمة أقسام «الكل» فعلياً عبر pinnedPositions، وليس فقط عبر ترتيب قائمة الإعدادات.
- الحفاظ على القسم القديم «أقسام عامة - منصة الكل» ومرادفاته؛ لا تُحذف بياناته. إذا وجدت سجلات وصفية مكررة بالاسم نفسه، تُعرض كقسم واحد من دون حذف السجلات الأصلية.
- تصحيح تصنيف الخدمات القديمة: المنصة الأصلية الصريحة (مثل Instagram) تتقدم على علامات تجميع عامة قديمة خاطئة. ويُعاد تطبيع platformScope عند الاستيراد الصريح.
- فك أسماء الأقسام المشفرة بـ URI/UTF-8، واستخدام مفتاح القسم كبديل عند فساد الاسم المخزن بعلامة الاستبدال.
- دمج عرض الأقسام والخدمات المكررة بالهوية الثابتة للمزود ومعرّف خدمته، من دون حذف أي سجل من Firebase.
- الحفاظ على آلية استعادة كتالوج Firebase: Firebase هو المصدر الأصلي؛ لا يُرفع كاش Railway إلا إذا كان موثقاً، ولا يُعلَن نجاح الاستعادة عند فراغ الخدمات مع وجود مؤشرات كتالوج.
- استعادة الكاش الموثق عند الحاجة، مع الحفاظ على المستخدمين والأرصدة والطلبات وسجلاتها.
- صفحة إنشاء الطلب بقيت بالشكل السابق R20.22: شريط منصات يدوي التمرير، لا حركة تلقائية، لا زر إيقاف للمستخدم، ولا بطاقة خطوات R20.21.
- تحسينات الأداء السابقة وملصقات القائمة الجانبية محفوظة.

البناء والنشر:
- Railway build command: npm run build
- Railway start command: npm start
- Health check: /healthz
- Node.js المطلوب: >=22.23.5 <23
- الاختبارات الكاملة: npm test

راجع DEPLOY_R20.23_AR.md قبل النشر. لا تحذف Railway Volume، ولا تغيّر متغيرات Firebase أو مسار SADA_DATA_DIR، ولا ترفع مجلد بيانات تشغيل محلي فوق بيانات الإنتاج.

ملاحظة مهمة: الحزمة لا تتضمن مجلد DATA أو ملفات .env أو مفاتيح Firebase Service Account أو أسرار المزودين أو node_modules. لم يتم النشر على Railway الإنتاجي من هذه البيئة؛ نتائج الفحص المرفقة من اختبارات محلية وقاعدة Firebase تجريبية.
