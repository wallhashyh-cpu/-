صدى العراق — الإصدار 3.2 — R20.3

حزمة التشغيل المضغوطة للمشروع. ملفات التشغيل موجودة مباشرة في جذر المشروع.

التشغيل والنشر:
1) Node.js 22.
2) npm install
3) npm run build
4) npm start
5) افحص /healthz و/api/release وتأكد من رقم البناء.

ما يميز الإصدار:
- ثلج خفيف عبر كامل التطبيق، بما في ذلك الدخول والتسجيل وإنشاء الطلب والطلبات؛ التحكم به من إعدادات لوحة الإدارة فقط.
- صفحة دخول/تسجيل بهوية بصرية أصلية مع الحفاظ على وظائف المصادقة.
- مستورد خدمات موحد يدعم تحديد المزود والخدمات أو الأقسام قبل تأكيد الرفع.
- دعم عدة مزودين نشطين بالتوازي مع حفظ معرف المزود على الخدمة.
- حذف آمن محدد النطاق بدلاً من مسح شامل غير محدد.

استرداد الخدمات:
زر «استرداد خدمات المزود» يفتح نافذة الاستيراد فقط. اختر المزود، اضغط «جلب خدمات المزود»، حدد الخدمات أو الأقسام المطلوبة، ثم اضغط «رفع الخدمات المحددة». لا يتم استيراد كامل الكتالوج تلقائياً.

حماية البيانات:
- لا ترفع مجلد data المحلي أو ملفات .env أو مفاتيح Firebase أو أسرار المزودين.
- احتفظ بمتغيرات Railway وFirebase وSESSION_SECRET وSADA_DATA_DIR وRailway Volume كما هي.
- لا تحذف قاعدة البيانات أو Volume ولا تعِد تهيئتهما أثناء التحديث.
- اجعل مستودع GitHub خاصاً؛ admin-auth.json يحتوي البريد الإداري وتجزئة scrypt لكلمة المرور.

الاختبارات داخل tests/smoke.js. لم يتم اختبار اتصال الإنتاج أو مزود حقيقي من بيئة البناء.
