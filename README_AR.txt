صدى العراق — الإصدار 3.2 / R20.17

الإصلاح الأساسي في هذا الإصدار:
1) Firebase هو المصدر الأساسي للخدمات والأقسام. عند نشر تحديث، يقرأ الخادم الخدمات من Firebase ويجدد كاش Railway منها؛ لا يرفع الكاش المحلي القديم فوق البيانات الموجودة في Firebase.
2) استعادة قاعدة البيانات من نسخة كاملة تعيد لقطة الخدمات والأقسام وترتيبها من تاريخ النسخة. بيانات المستخدمين والأرصدة والطلبات الحالية تبقى محفوظة ولا ترجع لقيم أقدم.
3) تم إصلاح الكتابة الشرطية مع Firebase باستخدام ETag + PUT، لأن Firebase REST لا يدعم If-Match مع PATCH.
4) تم الحفاظ على تصميم حسابي الجديد ووظائف الرصيد والطلبات والشحن والدعم والبريد وكلمة المرور.

التشغيل:
- Node: >=22.23.5 <23
- التثبيت: npm install
- الاختبار/البناء: npm test
- التشغيل: npm start

معاينة تصميم حسابي موجودة في account-preview.png.
اقرأ AUDIT_R20.17_AR.md لمعرفة تفاصيل الاختبارات، وDEPLOY_R20.17_AR.md قبل النشر.

تنبيه بيانات:
- لا تحذف Railway Volume ولا تغيّر إعدادات Firebase أثناء النشر.
- إذا كانت الخدمات ما زالت موجودة في Firebase، سيعيد الخادم تحميلها تلقائياً عند بدء التشغيل.
- إذا كانت الخدمات قد حُذفت فعلياً من Firebase، فلا يمكن استرجاعها إلا من نسخة احتياطية سابقة تحتويها.
- لم يتم تضمين بيانات قاعدة الإنتاج أو أسرار الاتصال في الحزمة.
