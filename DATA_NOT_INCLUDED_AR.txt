بيانات التشغيل لا تُضمّن في ملف ZIP:
- مجلد data المحلي وملفات المستخدمين والطلبات والأرصدة والنسخ التشغيلية المؤقتة.
- ملفات .env أو مفاتيح Firebase Service Account أو أسرار المزودين.

هذه البيانات تبقى في Railway Volume وFirebase الحاليين. لا تحذف Volume ولا تعِد تهيئة Firebase أثناء النشر. حافظ على SADA_DATA_DIR ومتغيرات الاتصال الحالية.

admin-auth.json يحتوي بريد المسؤول وتجزئة scrypt لكلمة المرور؛ يجب أن يبقى مستودع GitHub خاصاً.
لا يحتوي الملف المضغوط node_modules أو package-lock.json. يتم تثبيت الاعتماديات عبر npm install على Railway. لم يتوفر سجل npm أثناء محاولة إنشاء ملف القفل؛ لا تستخدم ملف قفل غير متحقق.
